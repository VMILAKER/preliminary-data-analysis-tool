# Preliminary Data Analysis Application
Tool for data analysis from .csv, .xlsx, .xls, and .json files with report generation.

Now two versions are available:
- Based on Streamlit with PyGWalker support and Pandas- [Streamlit_based_version](https://github.com/VMILAKER/preliminary-data-analysis-tool/tree/streamlit_version);
- Class version - [Class_version](https://github.com/VMILAKER/preliminary-data-analysis-tool/tree/class_version).
