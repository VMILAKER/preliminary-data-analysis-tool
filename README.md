# Инструмент предварительного анализа данных

Веб-приложение на Streamlit для исследования CSV, Excel (`.xlsx`, `.xls`) и JSON перед аналитикой или машинным обучением.

## Возможности

- Предпросмотр загрузки; выбор кодировки, разделителя, заголовка и листа Excel.
- Обработка вложенного JSON: раскрытие словарей в столбцы или сохранение вложенных значений как текста. Списки не размножают строки.
- Статистика, частоты значений, пропуски, смешанные типы, распознавание дат, email, телефонов и URL.
- Индекс качества DQI с пояснением метрик и весов.
- Графики распределений, корреляций и пропусков; интерактивное исследование через PyGWalker.
- Выбросы IQR и Isolation Forest с настраиваемой долей аномалий.
- Удаление дубликатов и выбросов, история очистки, отмена последних пяти действий и возврат исходных данных.
- Excel-отчёт с текущими данными, исходными индексами строк, результатами проверок, настройками и выбранным планом обработки пропусков.

## Запуск локально

Рекомендуется Python 3.12. Команды для PowerShell из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run main.py --server.port 8502
```

Открыть <http://localhost:8502>. В Linux/macOS используйте `.venv/bin/python` вместо `.venv\Scripts\python.exe`.

`requirements.txt` фиксирует прямые зависимости проверенного окружения; транзитивные зависимости выбирает pip. Для `.xls` включён `xlrd`. Streamlit зафиксирован на 1.50.0: используемый PyGWalker 0.5.0.1 интегрируется с его Tornado-сервером, поэтому обновлять эти пакеты нужно совместно.

## Запуск через Docker

```powershell
# Необязательно: для изменения порта скопируйте пример и отредактируйте STREAMLIT_PORT.
Copy-Item .env.example .env
docker compose up --build -d
docker compose ps
```

Порт по умолчанию — `8502`. Значение `STREAMLIT_PORT` из `.env` применяется одновременно к приложению, пробросу порта и проверке здоровья контейнера. Проверка здоровья использует Python и не требует curl.

## Как пользоваться

1. Загрузите файл, выберите параметры чтения и проверьте предпросмотр. Автоопределение заголовка и кодировки эвристическое: при неверном результате задайте их вручную.
2. Нажмите «Начать анализ». Изменение файла или параметров требует нового подтверждения предпросмотра и начинает новую историю.
3. Изучите проверки. Графики и PyGWalker включаются отдельно, чтобы не замедлять обычный просмотр.
4. При необходимости удалите дубликаты или выбросы. На кнопках указано число удаляемых строк. Отмена и восстановление находятся в боковой панели.
5. Выберите план обработки пропусков. Он сохраняется в отчёт, но автоматически не применяется к данным.
6. Нажмите «Подготовить Excel-отчёт», затем скачайте файл. Результаты Isolation Forest совпадают с текущим экраном. Дубликаты остаются в отчёте до явного удаления.

## Ограничения анализа

- DQI — эвристический индикатор, а не гарантия пригодности датасета. Константы учитываются в двух компонентах; веса показаны в интерфейсе.
- Даты проверяются по первым 2000 непустым значениям; доля дат относится к этой выборке.
- Isolation Forest использует строки без пропусков и бесконечностей во всех числовых столбцах. Найденные аномалии требуют проверки по смыслу данных.
- Для IQR рассматриваются числовые столбцы с минимум пятью уникальными значениями; названия с `id` исключаются существующей эвристикой.
- Очистка хранится в памяти текущей сессии. Кеш результатов ограничен 10 минутами и восемью наборами, кеш загрузки — четырьмя наборами. Большие файлы требуют достаточного объёма памяти.
- В интерфейсе доступен экспорт в Excel. Вспомогательные функции CSV/PDF пока не подключены к скачиванию.

## Проверка

```powershell
.venv\Scripts\python.exe -m pip check
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверки охватывают загрузку, вложенный JSON, DQI, кеширование, отмену очистки, содержимое Excel и действия в интерфейсе Streamlit. GitHub Actions запускает их на Python 3.12 и проверяет сборку Docker.

Файлы приложения: `main.py` — загрузка и сессия; `src/app.py` — интерфейс; `src/analysis.py` — общие результаты и кеш; `src/session.py` — история очистки; `src/utilities.py` — загрузка, графики и экспорт; `src/data_validator.py` — проверки качества.

Описание отдельных изменений и исправляемых проблем: [CHANGES.md](CHANGES.md).
